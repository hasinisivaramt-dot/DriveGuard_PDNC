# ml/

Python ML/DL pipeline — built across Phases 1-6 of the roadmap.

Will contain:
- `pipeline/` — data cleaning, feature engineering, sliding-window generation
- `baselines/` — Linear Regression, Random Forest, Logistic Regression, Decision Tree, KNN, SVM
- `deep_learning/` — ANN, LSTM, GRU (PyTorch) multi-task model (failure prob + RUL + health score)
- `explainability/` — SHAP analysis, degradation trend, risk persistence
- `evaluation/` — MAE/RMSE (RUL), Accuracy/Precision/Recall/F1/ROC-AUC/Confusion Matrix (classification)
All results here will come from real experiments on the chosen dataset — no fabricated numbers.
